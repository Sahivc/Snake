初始化地图，初始食物坐标，初始化一条蛇，初始画面。接受用户输入，判断转向或者游戏结束。向前移动，判断是否触碰边界，是则游戏结束，否则判断是否吃到食物，是则生成新的食物，渲染，停顿，清屏

![[Snake 流程.drawio.svg]]

注意：游戏开始前要隐藏光标 `std::cout << "\033[?25l"`; 游戏结束时要恢复光标 `std::cout << "\033[?25h"`

接受用户输入并不阻塞程序依赖：`conio.h` 
- 判断用户是否输入：`_kbhit()` 
- 获取用户输入 `_getch()`

停顿依赖：`chrono` and `thread`
```
std::this_thread::sleep_for(
	std::chrono::milliseconds(200)
)
```

清屏：`cout << "\033[2J\033[H";` 

游戏结束流程：清屏，打印游戏结束提示和分数，召回光标，exit(0)
